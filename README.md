# Gulfam Smart Chat — WordPress Plugin

**WhatsApp Chat & Lead Capture Plugin with CRM Dashboard**

A lightweight, responsive WordPress plugin that helps businesses connect with customers through WhatsApp and manage incoming leads directly from the WordPress admin dashboard.

## Features

- Floating WhatsApp chat widget
- Fullscreen, minimize, restore and close controls
- Customizable chat colors, messages and position
- Lead capture form with name, email, phone and message
- Customer consent checkbox
- WordPress leads management dashboard
- Direct WhatsApp chat links for customer phone numbers
- Gmail compose links for customer email addresses
- Lead contact status management
- Admin notes for customer follow-ups
- Lead deletion with confirmation
- Responsive design for desktop and mobile

## Technologies Used

- PHP
- JavaScript
- HTML5
- CSS3
- WordPress Plugin API
- WordPress Database API

## Installation

1. Download the packaged plugin ZIP.
2. Log in to your WordPress admin dashboard.
3. Navigate to Plugins → Add New Plugin → Upload Plugin.
4. Select the plugin ZIP and click Install Now.
5. Activate the plugin.
6. Open Gulfam Smart Chat settings and configure your WhatsApp number.

## Lead Management

The admin dashboard allows website administrators to view captured leads, contact customers through WhatsApp or Gmail, update contact statuses, add follow-up notes, and delete leads.
